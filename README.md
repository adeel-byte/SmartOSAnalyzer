# SmartOSAnalyzer

SmartOSAnalyzer is an advanced Operating System simulation and monitoring application developed using Python and PyQt6. The project combines real-time system monitoring with visualization of core Operating System concepts such as CPU scheduling, process management, and memory management.

## 🚀 Features

- Real-time CPU and RAM monitoring
- Process management and monitoring
- FCFS Scheduling Algorithm
- SJF Scheduling Algorithm
- Round Robin Scheduling
- Priority Scheduling
- Gantt Chart Visualization
- FIFO Page Replacement
- LRU Page Replacement
- Login & Registration System
- Interactive GUI Dashboard

## 🛠️ Technologies Used

- Python
- PyQt6
- psutil
- SQLite
- pyqtgraph
